# TerraScope · 此刻 — 30 秒电影感宣传片

横屏 1920×1080 / 30 fps，2.39:1 遮幅，只有音效，没有旁白和音乐。三个长镜头，卡在 100 BPM 的小节线上硬切：

| 镜头 | 时间 | 内容 |
| --- | --- | --- |
| A「此刻」 | 0–7.2 s | 夜侧城市上空，镜头爬升，太阳从地球边缘后露出（轨道日出）；标题「此刻」；俯冲向城市灯光，白闪 |
| B「上升」 | 7.2–19.2 s | 同一片夜空的航班（锁定一架真实航班）→ 追上并在约 430 m 外掠过空间站（3D 模型）→ 拉高，星链壳层淡入 |
| C「风暴」 | 19.2–30 s | 磁层侧视（太阳在左）→ 俯冲穿过大气（白闪）→ 离该地区最近的夜侧极光带 → 上升告别，片尾 |

**拍哪里**不固定：在航班密集的核心区（西欧/中欧、美国东部、美国西南、东亚、海湾地区、印度、东南亚、澳大利亚东南、巴西东南；`story.mjs` 的 `REGIONS`）里，自动选空间站最近一次合格过境的地方；过境点正下方就是镜头 A、B 的锚点，极光段去同一半球、该经度上的极光带（偶极子模型估算的磁纬 66°）。

## 真实性

- **一次快照，处处一致**：`plan.mjs` 在开拍时刻把所有实时数据（ADS-B 航班、CelesTrak 轨道根数、NOAA 极光 / Kp / 太阳风）录下来，每个录制分段都回放这一份（`browser.mjs`），HUD 上的数字也来自它。
- **虚拟时间**：录制模式下，网站的"现在"被固定为 T0 + 视频时间（`src/clock.ts`），卫星、星链、航班推算、太阳位置都按视频时间移动，与每帧渲染多慢无关。
- **锁定框落在真实目标上**：每帧从页面取空间站和航班的屏幕坐标（`project`）。
- **空间站模型**：NASA 3D Resources 的 "International Space Station (ISS) (B)"（NASA 声明无版权）。`trim_model.py` 去掉文件里漂在站体上方的 7 个零件；按真实尺寸缩放（翼展 109 m），桁架横跨轨道、舱段沿飞行方向。位置是 SGP4 推算的真实位置，姿态是近似，画面标注 `MODEL · ATTITUDE APPROX.`。
- 粒子和磁层边界标注 `ILLUSTRATIVE`；极光弱就如实呈现。

## 什么时候能拍

需要空间站**被阳光照亮**、而它正下方（航班密集核心区内）**已经天黑**（太阳高度低于 -6°），极光段看向的地方也在夜侧。空间站在夜空里还被照亮，只发生在晨昏线附近、而且多在它轨道的高纬端（约 50°），所以合格的地方随季节和轨道朝向变化：有时几小时一次，有时一两天里只有欧洲上空有。`plan.mjs` 会列出接下来的窗口和地点；正式录制要在窗口前 5 小时内启动。

## 运行

GitHub Actions → **Cinematic promo** → Run workflow：

- `mode = preview`：不等待，拍约 45 张关键帧并合成 HUD，用来检查构图和空间站模型朝向（推送 `video/cinematic/**` 到本分支时也会自动跑）。
- `mode = full`：在窗口前 `max_wait_min` 分钟内启动（默认 300），等到窗口开拍；11 个分段并行录 900 帧，最后调色、HUD、音效、编码。
- `model_rotation`：模型自身坐标轴的修正（航向,俯仰,横滚，度），默认 `90,0,90` 适配 NASA 模型。

产物（Artifacts）：`terrascope-cinematic-full` 里有 MP4、review 截图、plan.json（数据来源与读数）、每段的录制记录。

## 文件

| 文件 | 作用 |
| --- | --- |
| `story.mjs` | 分镜：每帧的镜头位姿、图层、淡入淡出、白闪 / 黑场 |
| `geometry.mjs` | WGS84、太阳方向、SGP4、单调插值 |
| `pass.mjs` | 寻找可拍的时间和地点 |
| `plan.mjs` | 找窗口、等待、数据快照、选锁定航班 |
| `capture.mjs` | 按帧录制（虚拟时间 + 位姿 + 等瓦片加载完） |
| `render.py` | 遮幅、调色、HUD、锁定框、片尾、编码（bt709，crf 16） |
| `trim_model.py` | 清理 NASA 空间站模型里的游离零件 |
| `sfx.py` | 音效：环境声、呼啸、冲击、HUD 提示音、计数声；太阳风音高由实测风速决定 |

测试：`tests/cinematic.test.mjs`（镜头连续性、空间站掠过距离、窗口条件）、`tests/e2e/app.spec.ts`（录制接口）。
