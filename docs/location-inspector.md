# 地点概览

点击地表或从搜索/分享链接选定坐标，地点面板分为“概览 / 天气 / 地质”，默认打开概览，更换地点时重置为概览。来源说明默认折叠。火山、地震的专用详情保持原样。

- 附近城市：已有人工整理的城市坐标，球面距离不超过 300 km；仅为参考，不用于判定行政归属。没有收录城市时明确说明，不猜测名称或国家。
- 环境数据：[Open-Meteo Forecast API](https://open-meteo.com/en/docs)，包括天气状况、2 米气温、体感温度、相对湿度、地表气压、云量、海拔和时区。明确标注数值模式估计、数据时间与网格位置偏差，不宣称逐点实测。海拔不能用来推断海底水深。
- 地点天气与 NOAA 气温热力图是独立数据产品，不保证模式或有效时间相同。

仅在实时模式、地点详情的天气分类可见且已选定坐标时发出天气请求。快速点击延迟 250 ms；更换地点、关闭面板或切换历史会终止旧请求。面板保持打开时每 15 分钟尝试更新，隐藏页面暂停轮询。最多缓存 50 个地点，返回字段的单位、数值范围、时区、时效和网格距离均会校验。缺失指标显示“未提供”，不填充零。

天气查询和地质查询相互独立。API 不可用时保留坐标、附近城市与地质记录；历史回放明确隐藏当前天气，不将当前模式结果伪装成历史天气。

验证：`npm test`；`npm run typecheck`；`npm run build`；`npx playwright test -c playwright.weather.config.ts`（可通过 `PW_CHROMIUM_PATH` 指定 Chrome）。浏览器测试使用明确的合成接口夹具，另已在真实 API 上检查地点到画面的完整链路。

选定坐标会显示琥珀色地点标记（与蓝色“我的位置”区分），更换地点更新，选择火山/地震时隐藏。坐标区提供居中、复制和分享按钮；复制使用纬度在前的六位小数格式，分享链接恢复所选坐标。分类支持左右方向键及 Home/End。
