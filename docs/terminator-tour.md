# 晨昏线旅行

顶部“旅行”进入，默认沿日出侧巡游；可切换日落侧，暂停/继续，以及选择 0.5×、1×、2× 速度。日出或日落各占晨昏圈的一半，镜头沿对应半圈平滑往返，一个周期约 3 分钟（1×），不是模拟太阳加速移动。

轨迹由现有 `subsolarPoint` 太阳位置近似算法计算：在垂直太阳方向的平面上构造正交基，生成太阳中心高度为 0° 的地表坐标。没有考虑折射、太阳视半径或地形，不能作为精确的当地日出日落时刻预报。界面显示的当地太阳时按经度计算，不是行政时区时间。附近城市仅作为位置参考。

沿用场景时间：实时模式跟随真实时间，历史模式跟随所选时刻；速度只改变巡游路径上的镜头速度。手动拖动/缩放自动暂停，Esc 或“退出旅行”结束。搜索跳转、快捷定位、居中地点及卫星跟踪会退出镜头巡游，避免相机争夺控制。退出保留当前视角，恢复进入前的昼夜光照和气温图层开关。

进入时临时启用昼夜光照、隐藏气温色带并收起侧栏，以便看清晨昏分界。功能按需加载，未进入时不创建动画循环、不发额外网络请求。动画最多每秒更新 24 次相机，位置文字每秒两次，后台页面不推进路径。仅修改独立功能分支，不触发视频录制流程。

验证包含春分、夏至、秋分、冬至的几何地平线、日出/日落方向、路径周期和太阳时跨日，以及浏览器中的模式切换、暂停恢复、手动操作暂停、退出和图层恢复。
